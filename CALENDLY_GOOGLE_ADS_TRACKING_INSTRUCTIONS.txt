IMPORTANT IMPLEMENTATION RULES
==============================

1. Install/configure the main Google Ads account tag once.
2. Do not put either conversion event snippet in the page <head>.
3. Do not fire a lead conversion when the page loads.
4. Do not fire a lead conversion merely when the submit button is clicked.
5. Fire the lead conversion only after the backend confirms that the form was
   submitted successfully.
6. Fire the Calendly conversion only after Calendly sends the confirmed
   calendly.event_scheduled event.
7. Opening Calendly, viewing a calendar, or selecting a time is not a completed
   booking and must not fire the booking conversion.

STEP 3: CALENDLY BOOKING CONVERSION
====================================

Recommended codebase location:

src/components/google-ads/google-ads-scheduler-modal.tsx

The Calendly scheduler must be embedded on the Zevitech page for this listener
to work.

Make sure useEffect is imported:

import { useEffect, useMemo, useRef } from "react";

Add this effect inside the Calendly scheduler component:

useEffect(() => {
  if (!open || !schedulerUrl) return;

  const handleCalendlyMessage = (event: MessageEvent) => {
    // Accept messages only from Calendly.
    if (
      !/^https:\/\/([a-z0-9-]+\.)?calendly\.com$/i.test(event.origin)
    ) {
      return;
    }

    // Do not fire until Calendly confirms the completed booking.
    if (event.data?.event !== "calendly.event_scheduled") {
      return;
    }

    const eventUri = event.data?.payload?.event?.uri;

    const bookingId =
      typeof eventUri === "string"
        ? eventUri.split("/").pop()
        : `calendly-${Date.now()}`;

    const guardKey = `calendly-conversion-${bookingId}`;

    // Prevent the same booking from being reported more than once.
    if (window.sessionStorage.getItem(guardKey)) {
      return;
    }

    window.sessionStorage.setItem(guardKey, "1");

    window.gtag?.("event", "conversion", {
      send_to: "AW-18263994803/qzLGCI_kvNYcELPj-YRE",
      value: 1,
      currency: "USD",
      transaction_id: bookingId
    });

    // Optional GA4 analytics event.
    window.gtag?.("event", "ga_scheduler_booked", {
      provider: "calendly",
      page_context: "google-ads-landing"
    });
  };

  window.addEventListener("message", handleCalendlyMessage);

  return () => {
    window.removeEventListener("message", handleCalendlyMessage);
  };
}, [open, schedulerUrl]);

SEPARATE-TAB WARNING
====================

The window message listener works when Calendly is embedded inside the
Zevitech landing page.

If Calendly opens in a separate browser tab or window, the landing page cannot
reliably receive calendly.event_scheduled. In that case, use one of these:

1. A Calendly webhook handled by the backend.
2. A Calendly confirmation redirect to a dedicated thank-you page.
3. A server-side Calendly integration that reports the confirmed booking to
   Google Ads.

Do not track an external Calendly-link click as a completed appointment.
